# Contributing

Thanks for your interest in the Same-Day AI Microservice Menu. This repo is part of a supervised charity income-generation experiment — all net proceeds go toward school supplies for children in need.

## Ways to contribute

### Report an issue
- Found a typo or unclear service description? Open a GitHub issue.
- Have a service idea that fits the same-day, fixed-price model? Describe it.

### Suggest a service
If you see a gap in the service menu (a common need that could be delivered same-day), open an issue with:
- The service description
- Typical buyer scenario
- Suggested fixed price
- What the deliverable would include

### Request a service (paid)
See the README service menu. Payment channel is pending verification; contact via GitHub issues in the meantime. Delivery is same-day for requests received before 3pm CT.

## Guidelines

- **Keep it real.** Describe actual service needs, not hypotheticals.
- **No private data.** Never include passwords, student personal details, or confidential business information in issues.
- **Stay within platform rules.** Follow GitHub's terms and any relevant platform policies.
- **AI disclosure.** All service drafts use AI assistance plus human compliance review. AI disclosure is included in every deliverable.

## Boundaries

This repo does not accept:
- Fake credentials, fake testimonials, or fabricated results
- Impersonation or misleading claims about qualifications
- Spam scripts or bulk messaging tools
- Any content that violates platform ToS or privacy laws
- Services involving trading/speculation, gambling, or referral/pyramid schemes
