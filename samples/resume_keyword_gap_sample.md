## Buyer-provided facts needed

| Item | Needed? | Example |
|---|---:|---|
| Current resume text | Yes | Existing resume pasted as text or shared as a document |
| Target job title | Yes | Customer Support Coordinator |
| Target job post | Yes | Official job description or listing link |
| Non-negotiable facts | Yes | Actual experience, tools, dates, certifications |
| Sensitive info removed | Yes | Address, phone, private identifiers may be redacted |

## Example target role

Customer Support Coordinator for a small software company.

## Common job-post keywords found

| Keyword / phrase | Why it matters | Resume action |
|---|---|---|
| Customer support | Core role match | Put in summary and recent role bullets if truthful |
| CRM | Tool category | Name actual tools used, e.g. HubSpot, Salesforce, Zendesk |
| Ticket resolution | Outcome phrase | Add metric if buyer has real data |
| Cross-functional communication | Collaboration signal | Add example with sales/product/operations if true |
| Documentation | Process skill | Mention help docs, SOPs, macros, or templates created |

## Before / after bullet examples

### Before

- Helped customers with problems and answered emails.

### After

- Resolved customer email and chat requests using [actual CRM/tool], documenting recurring issues and escalating product bugs to the appropriate team.

Why this is better: it names the support channel, tool category, documentation behavior, and escalation workflow without inventing numbers.

### Before

- Worked with team to improve customer service.

### After

- Coordinated with [team names] to clarify customer issues, update reply templates, and reduce repeated back-and-forth on common requests.

Why this is better: it explains the collaboration and concrete output.

## Summary rewrite sample

Original:

> Hard worker looking for a customer service job. Good communication skills and fast learner.

Improved:

> Customer support professional with experience handling email/chat requests, organizing recurring customer issues, and creating clearer internal notes for follow-up. Comfortable learning new tools quickly and working with teammates to resolve customer problems accurately.

## Missing-proof questions for the buyer

Before adding numbers or stronger claims, ask:

1. Which support tools or CRMs have you actually used?
2. About how many tickets, calls, chats, or emails did you handle per day/week?
3. Did you create or update any templates, help docs, or SOPs?
4. Did you train anyone or help onboard teammates?
5. Do you have real ratings, response-time improvements, or customer feedback you can cite?

## Same-day deliverable format

A real paid quick pass would include:

- Edited professional summary.
- 5-8 stronger resume bullets using only buyer-provided facts.
- Keyword gap table from the target job post.
- Cover/application message draft.
- Follow-up questions where evidence is missing.
- Final warning list: claims not to make unless verified.
