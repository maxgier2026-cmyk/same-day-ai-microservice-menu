# Quick Turnaround Delivery Checklist

Status: READY_TO_USE_INTERNAL_CHECKLIST
Purpose: make same-day AI-assisted microservice work faster to fulfill once a real buyer/payment path exists.

## Universal intake gate

- [ ] Buyer selected one fixed-price service.
- [ ] Buyer provided only real facts.
- [ ] Buyer removed private/sensitive data where possible.
- [ ] Platform/legal boundaries checked.
- [ ] Payment channel verified before collecting money.
- [ ] Delivery time promised only after scope is clear.

## Resume quick pass

Required inputs:

- Existing resume text.
- Target job title and job post.
- Actual work history, tools, dates, education, and certifications.
- Any real metrics the buyer can support.

Delivery pack:

- Summary rewrite.
- Bullet rewrites.
- Keyword gap table.
- Cover/application message.
- Evidence-needed questions.
- One revision boundary.

## Marketplace listing cleanup

Required inputs:

- Item category, brand/model/condition.
- Existing listing title and description.
- Photos or photo notes.
- Platform name.
- Known defects or limitations.

Delivery pack:

- Search-friendly title options.
- Honest description.
- Pricing/positioning notes.
- Photo checklist.
- Buyer reply scripts.
- Warning list for unsupported claims.

## Small-business AI mini-audit

Required inputs:

- Business type.
- One workflow to review.
- Current steps and bottleneck.
- Tools already used.
- What must not be automated.

Delivery pack:

- Workflow map.
- 3 practical AI use cases.
- Prompt/reply templates.
- No-code automation sketch.
- Risk/privacy notes.
- 7-day implementation checklist.
